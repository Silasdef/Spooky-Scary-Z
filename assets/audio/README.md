# Dossier Audio & Bruitages (assets/audio/)

Déposez ici les fichiers audio WAV ou OGG du projet. Les scripts vérifient automatiquement l'existence de chaque fichier avec `ResourceLoader.exists()` avant la lecture.

| Nom du Fichier | Description | Utilisé par |
|---|---|---|
| `menu_theme.wav` | Musique d'ambiance angoissante du menu | `MainMenu.gd` |
| `button_click.wav` | Bruitage de clic d'interface | `MainMenu.gd` |
| `game_theme.wav` | Musique de survie en jeu | `Map.gd` |
| `laser_shot.wav` | Son de tir du Pistolet Laser vert BO2 | `LaserGun.gd` |
| `laser_hit.wav` | Son d'impact laser sur les zombies | `LaserProjectile.gd` |
| `sword_swing.wav` | Coup tranchant de la Dragonslayer | `Dragonslayer.gd` |
| `boomerang_whoosh.wav` | Sifflement de rotation faucille & marteau | `CommunistBoomerang.gd` |
| `lightning_strike.wav` | Coup de tonnerre de l'éclair de Frankenstein | `LightningStrike.gd` |
| `mystery_box_jingle.wav` | Jingle légendaire de la Boîte Mystère BO2 | `Chest.gd` |
| `xp_pickup.wav` | Son d'aspiration / collecte de gemme XP | `LootGem.gd` |
| `level_up.wav` | Son de montée de niveau | `Player.gd` |
| `player_hurt.wav` | Son de blessure du joueur | `Player.gd` |
| `dash.wav` | Bruit de propulsion rapide du Dash | `Player.gd` |
| `enemy_hurt.wav` | Bruitage d'impact / gémissement d'ennemi | `EnemyBase.gd` |
| `dog_growl.wav` | Aboiement / grognement du Chien Zombie | `ZombieDog.gd` |
| `frankenstein_roar.wav` | Rugissement du Boss Frankenstein | `FrankensteinBoss.gd` |

# Dossier des Sprites (assets/sprites/)

Déposez ici les textures PNG du projet. Le code détecte automatiquement la présence de ces fichiers au runtime grâce à `ResourceLoader.exists()`. En leur absence, les scripts génèrent un rendu procédural (`_draw()`) soigné.

| Nom du Fichier | Description | Utilisé par |
|---|---|---|
| `player.png` | Sprite du joueur / survivant | `Player.gd` |
| `gem_xp.png` | Gemme de loot d'expérience | `LootGem.gd` |
| `laser_projectile.png` | Faisceau / projectile laser vert | `LaserProjectile.gd` |
| `laser_gun.png` | Sprite du pistolet laser BO2 | `LaserGun.gd` |
| `dragonslayer.png` | Épée colossale type Guts | `Dragonslayer.gd` |
| `sickle_hammer.png` | Faucille et marteau orbitaux | `CommunistBoomerang.gd` |
| `zombie_basic.png` | Zombie standard | `ZombieBasic.gd` |
| `zombie_pumpkin.png` | Variante zombie tête de citrouille (1/8) | `ZombieBasic.gd` |
| `zombie_dog.png` | Chien zombie rapide | `ZombieDog.gd` |
| `frankenstein_boss.png` | Boss Frankenstein lanceur d'éclairs | `FrankensteinBoss.gd` |
| `mystery_box.png` | Boîte Mystère type BO2 | `Chest.gd` |

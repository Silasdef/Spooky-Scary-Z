# 🧟 SpookyScaryZ

**SpookyScaryZ** est un jeu d'action / *bullet heaven* en 2D développé sur **Godot 4** dans le cadre d'une Game Jam. Incarnez un héros isolé face à des vagues exponentielles de zombies, améliorez votre équipement et survivez le plus longtemps possible !

---

## 🎮 Gameplay & Features

- **Tir automatique :** Un Pistolet Laser dévastateur qui demande une gestion fine de la cadence de tir.
- **Attaques circulaires :** Une Faucille tournoyante pour tuer les zombies en mid distance.
- **Dragon Slayer :** Epée de Guts qui tape au corp à corp.
- **Mouvements dynamiques :** 
  - **Dash :** Esquivez les attaques avec un court temps d'invulnérabilité.
  - **Tayon (Aspiration) :** Attirez tout le loot d'expérience à distance.
  - **Régénération de PV :** Régénère les PV.
